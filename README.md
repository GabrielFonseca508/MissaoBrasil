# 🇧🇷 MissãoBrasil

O **Missão Brasil** é um projeto acadêmico desenvolvido com o objetivo de apresentar informações sobre o Exército Brasileiro e suas diferentes Qualificações Militares (QMs/QMS) de forma interativa e educativa.

---

## 🎯 Proposta

A plataforma foi criada para ajudar os usuários a conhecerem melhor as áreas militares, suas funções e características, utilizando:

- Interface moderna
- Quizzes interativos
- Dashboards com dados dinâmicos

---

## 🧠 Tecnologias Utilizadas

- HTML
- CSS
- JavaScript
- MySQL Workbench
- Node.js
- Canva
- Trello
- VirtualBox
- GitHub
- Git Bash

---

## ⚙️ Funcionalidades

- Sistema de login e cadastro
- Quiz interativo
- Dashboard com gráficos e estatísticas
- Explicações sobre QMs/QMS
- Integração com banco de dados
- Sistema de sessão
- Interface dinâmica e responsiva

---

## 🎓 Objetivo Acadêmico

O desenvolvimento do projeto teve como foco a aplicação prática de conhecimentos adquiridos durante os estudos, envolvendo:

- Desenvolvimento Front-end
- Desenvolvimento Back-end
- Integração com APIs
- Banco de dados
- Manipulação de dados e gráficos
- Organização e versionamento de projetos
