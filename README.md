Missão Brasil
Sobre o Projeto

O Missão Brasil é um projeto acadêmico desenvolvido com o objetivo de apresentar informações sobre o Exército Brasileiro e suas diferentes Qualificações Militares (QMs/QMS) de forma interativa e educativa.

A plataforma foi criada para ajudar os usuários a conhecerem melhor as áreas militares, suas funções e características, utilizando uma interface moderna, quizzes interativos e dashboards com dados dinâmicos.

O projeto une tecnologia e informação, proporcionando uma experiência intuitiva enquanto aplica conceitos completos de desenvolvimento web.

Funcionalidades
Sistema de login e cadastro;
Quiz interativo;
Dashboard com gráficos e estatísticas;
Explicações sobre QMs/QMS;
Integração com banco de dados;
Sistema de sessão;
Interface dinâmica e responsiva.
